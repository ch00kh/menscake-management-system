# 결정 기록 (ADR)

**왜 그렇게 정했는지**를 남깁니다. 설계 문서는 도메인별로 묶여 있어서 "이건 왜
이렇게 됐지"를 찾으려면 문서 전체를 읽어야 합니다. 여기는 결정과 **기각한 대안**만
모여 있습니다.

번호는 [TODO.md](../../TODO.md)의 단계와 1:1입니다.

| # | 단계 | 다루는 것 | 상태 |

| [001](ADR-001-기반.md) | TODO 1 | 표기 · 값 · 식별자 · git · 테마 | 확정 |
| [002](ADR-002-도메인.md) | TODO 2 | 도메인 9개의 모델과 규칙 | 확정 |

5단계(착수)는 아직 결정이 없습니다.

---

## 규칙

- **번호는 불변입니다.** 뒤집힌 결정도 지우지 않습니다 — 해당 항목에 `대체됨`을
  달고 새 결정을 아래에 붙입니다
- 각 결정은 **검토한 대안과 기각 사유**를 반드시 적습니다. 그게 없으면 6개월 뒤에
  같은 논의를 다시 합니다
- 여기는 **결정**만 있습니다. 스키마와 화면 명세는 설계 문서에 있고, 각 항목에서
  링크합니다
